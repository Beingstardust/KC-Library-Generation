# Structural source-window rehydration V1E

Applies a generic source-overlay source-block promotion and a narrow direct-overlay rehydration exemption. The exemption only applies when source-overlay generation already promoted a target-bound source_block_text and the direct-overlay stage verifies that the promoted text is still non-fragmentary, target-bound, and structurally safe. No domain-specific production logic, model-specific logic, scoring-threshold change, ranking change, pack-admission change, active-pointer mutation, full144 run, or model call is introduced.
