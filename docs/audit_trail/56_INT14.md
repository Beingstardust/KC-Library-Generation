# 56. INT-14: a repair that is well formed can still be worse than the abstention it replaced

INT-13 made two repairs reachable that had never executed. Reading what they then produced is how
this one was found. Seven repairs fired; four of them wrote a draft *about the sources* and the
schema had no objection.

## What the repairs actually wrote

`invalid_abstention_content_repair` fires when a unit abstains on a packet the validator calls
draftable. The retry asks the model to draft from the admitted evidence. The acceptance test was
"did the retry parse, and does it validate", and on all seven it did.

Four of the seven bodies open like this:

> The provided evidence does not contain a specific definition, procedure, or structural
> description for a 'Bushy Decision Tree (Multi-split)' or distinguish it from a 'Binary Decision
> Tree'.

That is the abstention, restated at length, wearing the status `partial`. The unit had already
said the honest thing; the repair replaced it with a paragraph that says the same thing while
counting as a draft. Multi-class Confusion Matrix, Models of Randomness 1 and 2 do the same.

The other three are real. Learning Phase and Target Attribute are five-sentence definitions built
from the admitted passages, and both had been abstaining on packets with eight and more admitted
evidence rows. Classification Threshold is thinner, three sentences and mostly quotation, but what
it says is about the unit and is supported. It is the weakest keep, and it is a keep.

## The rule

`src/kc_l/kc_drafting/draft_hygiene.py` already knew how to recognise a sentence that talks about
the sources rather than the subject, because INT-12 needed exactly that. INT-14 gives the module
one exported decision, `body_describes_its_evidence`, and makes repair acceptance consult it:

```python
def body_describes_its_evidence(text: str) -> bool:
    meta, total, opens_with_meta = meta_commentary_profile(text)
    if not total:
        return False
    return opens_with_meta or (meta * 2 > total)
```

Two shapes of the same defect. A body that *opens* on the sources has announced that it is not a
definition before it says anything else. A body where most sentences are about the sources is one
regardless of how it opens.

Acceptance is now a conjunction rather than a schema check:

```python
def repair_resolved(repair, packet, repaired, repair_parse_error, repair_validation_issues):
    if repair_parse_error or repair_validation_issues:
        return False
    if repair.needs_repair(packet, repaired, repair_validation_issues):
        return False
    ...
    return not body_describes_its_evidence(body)
```

A rejected repair is not a failure state. The unit keeps the abstention it had, which was correct.

## The majority clause rejected nothing on this run, and stays

Honest attribution of the four rejections:

```
opening-signal only=4   majority only=0   both=0
```

Every one was caught by the opening signal. The proportion clause did no work. Keeping a clause
that has never fired needs a reason, and the reason is that the alternative is worse: the defect
is "the body is about the sources", and opening position is one shape it takes, not the definition
of it. Shipping only the shape that happened to occur in r3 would be the run-specific fix the rest
of this audit exists to avoid. The clause is exercised by INT14-1 and by sabotage, and it costs
nothing, since it flags zero of the 159.

## Sabotage

Seven cases, `_sabotage/sabotage_int14.py`. All seven now trip their target guard and the tree
restores byte-exact.

The first pass did not. "The majority signal is dropped" **survived**, and the reason was in the
tests, not the rule. INT14-1 and INT14-2 both used bodies that were simultaneously
majority-commentary and opening with commentary, so either signal alone satisfied both guards.
Deleting the majority clause changed no observable behaviour. A guard that either of two signals
can satisfy is testing neither.

Each guard now uses a body only its own signal can reject, and asserts the isolating property so
the cases cannot quietly drift back into overlap:

```
INT14-1  opens with content, majority commentary  ->  isolates the proportion clause
INT14-2  opens with commentary, minority overall  ->  isolates the opening clause
INT14-1b all commentary                           ->  the shape actually seen in the drafts
```

This is the third time in this audit that a guard passed for the wrong reason and only sabotage
said so. The other two were INT12-6, twice.

A second case reported "anchor not found", which is a sabotage that tests nothing while looking
like it ran. The cause was a Windows `scp` reintroducing CRLF into `int12_draft_hygiene.py`, so an
anchor written with newlines could not match. Line endings on the files this session touched are
normalised, and the sabotage harness reads and writes bytes.

four rejected units return to `abstained` and the three keeps survive as `partial`.
