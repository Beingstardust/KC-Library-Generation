# 62. INT-17: "grounded" answers a different question than the reader thinks

An external review of r3 said, correctly, that 115 `grounded` is not 115 correct, and listed
several units as "true but materially incomplete": ID3 Algorithm says which family it belongs to
and that it uses entropy, but not how it builds a tree; Ranker says it exists but not that it
scores, sorts and cuts.

The cause is not a drafting failure. It is that one word is carrying two questions.

## The rubric says so explicitly

The drafting prompt's status rules, verbatim:

> does the draft state EVERY element the evidence itself supports ... If yes, status is GROUNDED -
> regardless of length. A two-sentence draft built from two sentences of evidence is grounded if it
> omits nothing those two sentences offered. **Thin evidence, faithfully and completely used, is
> grounded, not partial.**

So `grounded` means *the draft used what it was given*. It says nothing about whether what it was
given was enough to teach the unit. ID3 is grounded on **one** substantive evidence row, and by
the rubric that is the right label.

Two questions, one word:

```
did the draft use what it was given?     -> status          (already reported)
was what it was given enough?            -> not reported at all
```

## What the pipeline already computes, and why it misses

`coverage_summary` has `low_confidence`:

```python
"low_confidence": (len(passages) <= 2 and max(relevances) < 0.60)
```

A conjunction. It fires only when a packet is thin **and** its evidence scored badly, so a thin
packet whose single passage scored well passes silently. It flags 6 units, and all 6 had already
abstained (RMSE/MAE for Ordinal Targets, McNemar, Friedman, Nemenyi, Querying Phase). It catches
none of the review's category C.

## Measurement

`_completeness/diag_packet_thinness.py`, over the r2 packets, counting passages with at least 8
distinct content words:

```
substantive rows per packet: min 0  p25 5  median 8  p75 17  max 34
```

The units the review called materially incomplete:

```
ID3 Algorithm                              1 row   low_conf=False  support=draftable
Classification Threshold (Cutoff)          1 row   low_conf=False  support=draftable
External Index: Precision                  1 row   low_conf=False  support=draftable
Role of Test Sample Size                   2 rows  low_conf=False  support=draftable
Ranker (Filter Subcategory)                2 rows  low_conf=False  support=draftable
External Index: Recall                     3 rows  low_conf=False  support=draftable
```

Six of the eight, all in the bottom 21 of 159, every one of them silently `draftable` and not
`low_confidence`. The other two (Comparing Two Models, Threshold Effect on P/R/F1) have 6 and 9
rows and are genuinely a different problem.

The band as a whole: **18 units** are thin, drafted, and unflagged. Six are the review's category
C. Four more are units the review faulted on other grounds (Models of Randomness 1 and 2, which
r4 now abstains; Sequential Forward Generation, a taxonomy conflation; Spearman Rank Correlation,
a source-boundary case). So 10 of 18 appear somewhere in an independent expert's problem list, and
the remaining 8 are candidates it did not fault - Laplace Estimator among them, which the review
explicitly praised. This is a flag, not a gate, and it should never become one.

## The change

Additive fields on `coverage_summary`, nothing else:

```python
SUBSTANTIVE_PASSAGE_MIN_WORDS = 8
THIN_EVIDENCE_MAX_PASSAGES = 3

"substantive_passage_count": substantive_passage_count(passages),
"thin_evidence": substantive_passage_count(passages) <= THIN_EVIDENCE_MAX_PASSAGES,
```

No admission changes, no drops, no rescoring, no threshold moved, and `low_confidence` is left
exactly as it was. INT17-6 asserts the thing that makes this safe: **the drafting prompt never
reads `evidence_coverage`**, so no draft can change because of it.

Deliberately NOT done: changing the status rubric so thin packets produce `partial`. That would
make `grounded` mean something new, break comparability with every run already measured, and
overload the same word again rather than separating the two questions.

## Guards and sabotage

Seven guards. INT17-1/2 are the pair that matters: a one-substantive-passage packet is reported
thin **and** is not `low_confidence`, which is the gap being filled. INT17-5 asserts the two
signals actually disagree somewhere, since two signals that always agree mean one is redundant.
INT17-7 pins the pre-existing keys, because the summary is an output contract.

Five sabotages, all caught by their target guard, tree restored, suite green before and after.

## What is not solved

The other half of category C, where the packet has 6 to 9 rows and the draft still stops short
(Comparing Two Models defines the question and never gives `d = e1 - e2`), is untouched. An
attempt to measure it as "admitted evidence the draft never draws on" failed: by lexical overlap
the mean unused share is 0.64 across all 150 drafted units, good and bad alike, so it does not
discriminate. Recorded in `_completeness/diag_unused_evidence.py` so it is not tried again the
same way.
